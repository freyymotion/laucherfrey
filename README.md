# Frey Launcher

**Launcher para Android**

**Menos peso na tela inicial. Mais fluidez no dia a dia.**

O Frey Launcher nasceu de uma necessidade simples: fazer a tela inicial dos meus celulares mais modestos funcionar de forma mais fluida.

A ideia era criar uma alternativa leve, sem excesso de elementos ou efeitos desnecessários, mantendo o que realmente importa em um launcher: acessar aplicativos, organizar favoritos e personalizar a tela inicial.

O que começou como uma solução para uso próprio acabou virando um projeto independente: **Frey Launcher**.

## O que você encontra

- Uma tela inicial simples e direta.
- Gaveta para acessar os aplicativos instalados.
- Atalhos e aplicativos favoritos.
- Personalização da aparência com temas.
- Uma proposta de interface leve, pensada para evitar excessos.

## Para quem é?

Para quem prefere uma tela inicial simples, quer evitar enfeites desnecessários ou procura uma alternativa para dispositivos Android mais modestos.

**A proposta é simples:** menos distração, menos excesso e uma experiência mais fluida.

## Download

Acesse [Releases](https://github.com/freyymotion/laucherfrey/releases/latest) para encontrar as versões disponíveis do Frey Launcher.

- Android 6.0 ou superior.

## Desenvolvimento

Desenvolvido em Kotlin, com Android SDK e Gradle.

O Frey Launcher é um projeto independente, criado e mantido por **FREYY**.

Sugestões e relatos de problemas são bem-vindos na área de [Issues](https://github.com/freyymotion/laucherfrey/issues).
